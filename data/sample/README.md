# Sample data (synthetic)

Every file in this directory is **synthetic**: the values were generated by `tests/synthetic.py` with invented numbers and do not come from any measurement on the testbed. They show the file formats that the pipeline produces and consumes:

| File | Produced by | Format |
|---|---|---|
| `raw/device1-host_rep0.json`, `raw/device1-host_rep1.json`, `raw/device2-host_rep0.json` | `src/models/inference.py benchmark` on each device | `BenchmarkResults` (`docs/schemas/benchmark_results.schema.json`) |
| `monitor/device1.json` | `src/testbed/resource_monitor.py` | `ResourceTrace` (same schema) |
| `power/device1.json` | `src/network/power_measurement.py` | `PowerTrace` (same schema) |
| `latency/device1.json`, `latency/device2.json` | `src/network/latency_measurement.py` | latency record (`src/network/records.py`) |
| `final_latencies_averages.json` | `src/network/node_statistics.py` | per-node averages |
| `total_averages_of_benchmark_results.json` | `src/benchmarking/result_aggregation.py` | per-node profile averages |
| `calculated_max_partition_points.json` (+ `.details.json`) | `src/benchmarking/partition_calculator.py` | maximum feasible partition point per node |

Regenerate with `python -m tests.make_sample_data` from the repository root.
